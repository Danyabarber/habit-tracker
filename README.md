# Трекер привычек

## О проекте
Это веб-приложение для ежедневного отслеживания полезных привычек. 


**Демо-ссылка:** (https://danyabarber.github.io/habit-tracker/)

## Функционал (что умеет)
- Добавление, редактирование и удаление привычек.
- Выбор иконки для каждой привычки из библиотеки Google.
- Отметка выполнения привычки на сегодняшний день.
- Автоматический подсчёт серии дней подряд (streak).
- Сохранение всех данных в браузере (localStorage).
- Экран статистики: процент успешности, топ-3 лучших привычек.
- Экран календаря: визуальное отображение выполненных дней.
- Экран истории: список всех выполнений по датам.
- Темная и светлая темы.
- Адаптивный дизайн (телефон и компьютер).



## Как запустить
1. Скачать проект.
2. Открыть файл `index.html` в браузере.
